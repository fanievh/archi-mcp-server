# Effective-state gap registry — the pawl for "report EFFECTIVE state, never REQUESTED state".
#
# WHY THIS FILE EXISTS
#   The client of this server is an LLM agent that cannot see the canvas, so a mutating tool's
#   success response IS its only ground truth. A response that echoes the request while the model
#   diverged is a correctness defect, not a cosmetic one — the agent builds its next action on the
#   lie and the failure surfaces far downstream, unattributable.
#
#   Fixing one call site does nothing to stop the next tool being born with the same bug. So the
#   invariant is enforced by a contract test over EVERY registered tool
#   (EffectiveStateContractTest), and this file is that test's known-gap list.
#
# THE PAWL (can only tighten, never loosen)
#   EffectiveStateContractTest requires every registered tool to be classified exactly once:
#     * read-only            -> listed in the test's READ_ONLY set (no obligation; it mutates nothing)
#     * covered by an oracle -> listed in the test's ORACLES registry (actively asserted)
#     * a known gap          -> listed HERE, with a status and a reason
#   A tool in none of the three FAILS THE BUILD. That is the "a new tool must register or fail"
#   property: a tool that cannot report effective state must be DELIBERATELY added here, in a
#   reviewable commit, rather than quietly shipping the bug.
#
#   ENTRY_CEILING in EffectiveStateContractTest is LOWERED (only ever lowered) in the same commit
#   that removes an entry — the manual, reviewable "click", exactly as tools/size-ratchet.sh does
#   for CEILING_LOC. NEVER raise it. Every fix is one line deleted here and one ceiling click.
#
# LOCALE
#   If you sort this file, pin `LC_ALL=C`. An unpinned `sort` collates differently on macOS (dev)
#   and the C-locale CI runner; that exact false positive already shipped once against the
#   signature baseline (see tools/size-ratchet.sh, "locale pin: REQUIRED, not cosmetic").
#
# FORMAT
#   <tool-name> <STATUS> # <reason>
#   STATUS is one of:
#     KNOWN-GAP  — MEASURED to not report effective state. The defect is understood and located.
#     UNAUDITED  — mutating, but no oracle has been written for it yet. Not a claim of innocence:
#                  it is an explicit admission that nothing checks this tool. Auditing one may
#                  move it to an oracle (delete the line) or to KNOWN-GAP (same line count).
#   Blank lines and #-comments are ignored.
